# Runtime import provenance

Pharos Runtime was imported from [`Bobcatsfan33/keel`](https://github.com/Bobcatsfan33/keel)
at commit `9ec673bf5e70a4cd4720bd391639b49840b93c2b`.

The source snapshot is committed under [`runtime/python`](python) and retains its original
Apache-2.0 license and attribution. A signed snapshot commit is used instead of grafting the
upstream ancestry into Pharos because Pharos requires every introduced commit to satisfy its
DCO check. The source repository remains the historical record for pre-monorepo development.

Future runtime changes are made in this repository. The former repository should become a
read-only migration pointer after this branch is merged and released.
